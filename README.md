# Fresh — ملفات التحديث

الريبو ده **للملفات بس** — مفيش أي كود هنا. الكود في ريبو خاص منفصل.

برنامج Fresh بيسأل هنا لوحده من جوّاه:

`https://github.com/Ezatalorabi/fresh-releases/releases/latest/download/latest.json`

لو لقى نسخة أحدث بينزّلها ويتأكد من بصمتها (sha256)، وياخد نسخة احتياطية قبل ما يركّب،
ولو التركيب اتعثّر بيرجع للنسخة اللي قبلها لوحده. بيانات المحل ماتتلمسش في أي خطوة.

### كل إصدار فيه

| الملف | إيه ده |
|---|---|
| `Fresh-<النسخة>.zip` | حزمة البرنامج — للتثبيت والتحديث |
| `Fresh-<النسخة>.zip.sha256` | بصمة التحقق |
| `latest.json` | رقم النسخة + رابط الحزمة + البصمة — ده اللي البرنامج بيقراه |

> **ترتيب الرفع مهم:** الـzip الأول، و`latest.json` آخر حاجة — عشان ماحدش يشوف
> تحديث ورابطه لسه مش موجود.
